# ts-shell

Safe, zero-dependency Unix shell utilities for TS-OS.

## Commands
* cd(path?) — Change directory (defaults to home).
* mkdir(path) — Create directories recursively.
* ls() — List files in current directory.
* touch(file) — Create empty file.
* echo(text, file?) — Print text or write to file.
* cat(file) — Read file contents.
* grep(text, file) — Search text in file.
* cp(src, dest) — Copy file or folder.
* rm(path) — Delete file or folder recursively.
* top() — Show active CPU, memory, and uptime stats.
* exit() — Exit process.
